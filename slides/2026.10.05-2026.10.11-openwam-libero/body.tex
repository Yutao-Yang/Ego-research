\section{Motivation}
% ============================================================

\begin{frame}{Why reproduce OpenWAM-\texorpdfstring{$\alpha$}{alpha}?}
  \begin{itemize}
    \item OpenWAM-\texorpdfstring{$\alpha$}{alpha} is a world--action model:
          a video-generation backbone is joined with an action expert.
    \item The authors report \textbf{99.30\,\%} on the four standard LIBERO
          suites.
    \item Question: does the \emph{released} checkpoint reproduce that number
          under the \emph{native} task protocol?
  \end{itemize}
  \vfill
  \begin{block}{What is held fixed}
    Released weights, LIBERO task protocol, environment and budgets.
    No retraining, no per-seed tuning.
  \end{block}
\end{frame}

\section{Benchmark and setup}
% ============================================================

\begin{frame}{LIBERO at a glance}
  \begin{columns}[T]
    \begin{column}{0.5\linewidth}
      \begin{itemize}
        \item Four suites: Spatial, Object, Goal, LIBERO-10.
        \item 40 tasks $\times$ 50 episodes $=$ \textbf{2000} closed-loop
              episodes.
        \item 20\,Hz control; per-task budgets of 600 / 700 steps.
        \item Success is decided by the task's BDDL goal predicate.
      \end{itemize}

\begin{frame}{Headline result}

\section{Takeaway}
% ============================================================

\begin{frame}{What this shows --- and what it does not}
  \begin{itemize}
    \item The released checkpoint \textbf{reproduces the official score} to
          within $0.05$ percentage points.
    \item Agreement is about the aggregate number, not per-episode identity.
    \item No world-model video metric is claimed: the run stored no predicted
          future frames.
    \item The result must not be read as a fair architecture comparison with
          the other model in this project.
  \end{itemize}
\end{frame}
